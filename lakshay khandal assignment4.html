HTML Tags

In every HTML and tag marks the beginning & end of the document it declares the text that follows on HTML web page
that can be viewed in browser. These tags inform that the document is an HTML file. All HTML tags must reside within
the ----- tags.

Types of HTML Tages

HTML tags can be of two Types
1. Paired Tags
2. Singular Tags

Paired Tag

A tag is said to be paired if it, along with a companion tag e.g. those which have the opening and closing are called paired tag.
They hold or contain the text and other HTML elements between the two tags, so they also called container tags

Singular Tag

A singular tag dosen't have a companion tag i.e. some tags that do not require '<' tags they are called Empty tags, singular tags or standalone tags.
